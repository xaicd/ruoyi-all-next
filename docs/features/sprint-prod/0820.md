## 7. 分清核心基础模块与业务域，以及同进程 SDK / 跨服务 RPC

**用户原始输入：**

要分清哪些是 核心基础模块， 哪些 是业务域 模块；微服务 就涉及跨服务调用，rpc,grpc,dubbo,thirft等远程协议，序列化等如何定，rpc接口是否要有 facade 等涉及模式，接口暴露， 打包在同一个服务运行时，直接sdk内存调用，跨服务 独立运行部署时得 rpc
