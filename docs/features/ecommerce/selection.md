# 选型与研判（G0 · DAR）：电商平台

## 1. 候选方案

| 候选 | 类型 | 许可证 | 许可风险 |
|---|---|---|---|
| 本基座 + 新建 shop 域 | 自研 | 内部 | 无 |
| 独立开源电商套件 | 开源 | Apache-2.0 | 低 |
| 商业 SaaS 电商中台 | 商业 | 订阅 | 授权限制 |

## 2. 竞品对标

* yudao-cloud：电商与会员域齐备，RPC 契约组织值得学；但整套引入会冲散本工程的域边界。
* yudao-mall-uniapp：C 端按实体拆 api 与请求封装，已借鉴到 clients/expo。

## 3. 开源生态扫描

* 不需要新增运行时依赖：状态机用 shared/lib/state-machine，库存与支付走 Facade。
* 刻意不引入独立电商框架 —— 引入即两套库存语义。

## 4. License 合规结论

**结论: 可商用，无传染性风险。新引入依赖：无（本次选型的主要收益之一）。**
