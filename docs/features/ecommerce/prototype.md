**交互要点**
* 搜索栏回车即查；「重置」清空并回第一页
* 删除需二次确认；下架中的商品**保留**在列表（灰显），不隐藏
* 弹窗打开时**基底内容 inert**（Agent 不会误点到被遮挡元素，AGENTS §5.2.1）

## 4. 状态与空态

| 场景 | 表现 |
|---|---|
| 加载中 | 表格区一行「加载中...」，不整页遮罩 |
| 空数据 | 「暂无数据」，并保留搜索栏（可改条件重试） |
| 出错 | 红色提示条 + 可重试；**不静默吞掉** |
| 无权限 | 按钮不渲染（权限码驱动可见性，AGENTS §4.4） |
