# 选型与研判（G0 · DAR）：开源顶流技能吸收：Archify 架构可视化与 Strix 自主渗透防御

## 1. 候选方案

| 候选 | 类型 | 许可证 | 许可风险 |
|---|---|---|---|
| tt-a1i/archify | 开源工具 | MIT | 低 |
| usestrix/strix | 开源多智能体渗透 | Apache-2.0 | 低 |

## 2. 竞品对标

* 静态 PNG 架构截图易过期、不可交互 vs Archify 动态声明式 JSON + 交互式路径追踪

## 3. 开源生态扫描

* 对比评估了 Mermaid, PlantUML, Archify 与 Strix，最终选用星数最高且无运行时侵入的轻量级方案

## 4. License 合规结论

**结论: MIT 与 Apache-2.0 商业极其友好，允许闭源商业使用与修改二次分发，0 传染性风险。**
